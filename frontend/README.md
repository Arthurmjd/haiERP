# 海岚 ERP 前端

Vue 3 + TypeScript + Vite + Element Plus。管理员、销售、计划、生产、仓储、财务、人事、厂长共用一个入口；登录后按角色显示岗位工作台和优先导航，实际业务访问仍由后端权限控制。

```powershell
npm install
npm run dev
```

默认地址 `http://127.0.0.1:5173`，`/api` 代理到 `http://127.0.0.1:8080`。请先按根目录开发说明初始化独立演示库并启动后端。浏览器直接访问页面无需单独配置 API 密钥。

后端尚未启动时，可在登录页点击“进入演示预览”，或直接打开 `http://127.0.0.1:5173/preview`。预览仅在 Vite 开发模式启用；顶部可切换岗位，数据留在当前浏览器会话，不会向后端写入。岗位预览仅用于查看界面，不能代替真实账号权限联调。

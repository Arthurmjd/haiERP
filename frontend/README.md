# 海岚 ERP 前端

Vue 3 + TypeScript + Vite + Element Plus。管理员、销售、计划、生产、仓储、财务、人事、厂长共用一个入口；登录后按角色显示岗位工作台和优先导航，实际业务访问仍由后端权限控制。

```powershell
npm install
npm run dev
```

默认地址 `http://127.0.0.1:5173`，`/api` 代理到 `http://127.0.0.1:8080`。请先按根目录开发说明初始化独立演示库并启动后端。浏览器直接访问页面无需单独配置 API 密钥。

后端尚未启动时页面能打开，但登录后所有列表都是空的 —— 浏览器内的模拟数据预览（`/preview`、`api/demo.ts`）已移除，前端只走真实接口。先启动后端与 MySQL，再用下面八个账号登录；想验证权限差异就换账号：同一个财务页，`finance` 能登记收付款，`boss` 只能查看。

| 岗位 | 用户名 |
| --- | --- |
| 管理员 | `admin` |
| 销售 | `sales` |
| 计划员 | `planner` |
| 生产主管 | `production` |
| 仓管员 | `wh` |
| 财务 | `finance` |
| 人事 | `hr` |
| 厂长 | `boss` |

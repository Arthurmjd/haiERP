# 答辩手册（使用说明）

明天答辩，这四份材料按「先背、再看、再查、最后兜底」的顺序用：

| 文件 | 什么时候看 | 要背到什么程度 |
|---|---|---|
| `00-总讲稿.md` | **现在先看这个** | 3 分钟版能背下来；8 分钟版能照着讲；15 分钟版知道演示顺序 |
| `01-后端篇.md` | 讲后端之前 | 第 1~3 节必须熟；第 6 节（幂等）和第 8 节（权限）至少要能讲 30 秒 |
| `02-前端篇.md` | 讲前端之前 | 第 1~4 节必须熟；第 5 节（配置驱动）是最容易被追问的，也要会 |
| `03-问答速查.md` | 上台前 30 分钟翻 | 不用背全文，**背每条加粗那半句**；送命题和应急话术一定要看 |
| `04-Swagger演示.md` | 上台前 10 分钟过一遍 | 只需记住网址 `http://127.0.0.1:8080/swagger/` 和「三步拿 token」 |

## 60 秒上手路径

1. **记 6 个数字**：325 / 43 / 260 / 228 / 66 / 60（后端文件数 / 控制器 / 接口 / 权限注解 / 表 / 自检项）
2. **记 1 条主线**：报价 → 订单 → 采购 → 工单 → 领料 → 报工 → 完工 → 出货 → 应收 → 收款 → 成本
3. **记 3 个文件**：`ErpOrderService.java`、`ErpStockMapper.java`、`api/catalog.ts`（被质疑时能翻出来）
4. **记 1 句立场**：前端控体验，后端控安全；状态只走动作，库存只认流水。

## 时间紧的话，只看这三段

- `00-总讲稿.md` 的「二、8 分钟版」
- `01-后端篇.md` 的「6. 并发与幂等」+「8. 权限」
- `02-前端篇.md` 的「5. 配置驱动的列表页」

## 手册里每个数字都能现场验证

`00-总讲稿.md` 最后一节给了每个数字的验证命令。老师如果质疑"这些数字是不是编的"，就当场敲一条 `find ... | wc -l`。
